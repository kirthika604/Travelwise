# Project requirement 
## product overview
the product provide user with the place user could explore with users provided constraints and shows user all the required details about the place that may help user to choose righ place. platform provides user with a perfect route user can you with including multi-modal transport planning and time-based availability based on provided constraints.

## problwm statement
the real problem is that information need by the user are fragmented into multiple platform and it costs a lot of time and efforts of user to plan a trip. with all the platforms showing individual transport routes it may not be feasible for user. less knowledge about the public transport and fragmented information make choice of combination of transport difficult and hence moving towards bad travel planning.

##goals
-provide user with all the feasible places that user can explore acoordingly to the constraints provided by user. 
-give combination of places that user can explore with the given constraints.
-provide feasible combination transport user can use based on constraint and time-based availability.
-help user to plan a trip according to their interest(flexible).
